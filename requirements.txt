# PYTHON VERSION: 3.12 (see runtime.txt) — REQUIRED, not just recommended.
# Verified as the safest choice for this full stack: every package below
# (torch, sentence-transformers, spacy, faiss-cpu, chromadb, ragas) publishes
# mature, stable wheels for 3.12. Python 3.13 has partial support for some
# of these (spotty C-extension wheel availability as of this writing) and
# Python 3.14 (released Oct 2025) is too new — several packages here don't
# yet publish wheels for it at all, which silently falls back to slow/broken
# source builds or hard install failures. Do not deploy this project on
# anything other than 3.12.x until you've independently re-verified the
# full dependency chain on a newer interpreter.
